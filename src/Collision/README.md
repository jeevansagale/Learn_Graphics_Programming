# Collision and Player control

![Image](Assets/image.png)

## About 

- Simple player control and Collision detection using raylib and C++

- Used simple physics to detect player and the balls

### Controls
|Action | Key  |
|:----: | :---:|
|Up     | W    |
|Down   | S    |
|Left   | A    |
|Right  | D    |
