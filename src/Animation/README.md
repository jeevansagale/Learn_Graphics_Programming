# Sprite Animation

A small Raylib experiment that loads a sequence of idle sprite frames and displays them as a looping animation.

## Implementation

The program loads nine idle frames and advances to the next frame after a fixed time interval. The current frame is drawn each render loop.

- Framework: Raylib
- Language: C++
- Animation: frame-based sprite sequence
- Frame interval: 0.2 seconds
